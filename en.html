FAQ

Know the boundary before you install.

Is Connect a terminal?
Connect is a GUI-first multi-agent workspace. Every Claude, Codex, or shell panel still runs a real terminal; Connect organizes projects, panels, collaboration, and mobile control.
Which coding agents are supported?
The top bar provides fixed Claude Code, Codex, and shell entries. Any terminal CLI can run through shell; the current automated collaboration engine explicitly supports Claude and Codex.
Do I give Connect an API key or account?
No. You install and sign in to vendor CLIs yourself. Connect does not read vendor auth files, store or forward tokens, or provide a Connect AI account.
How do Claude and Codex collaborate?
The collaboration room gives the full room transcript to the mentioned agent. Claude can implement and Codex can review; one agent stays serial while different agents and rooms can run in parallel.
How does iPhone connect to Mac?
The Mac bridge starts off and binds only to a specific Tailscale or RFC1918 interface. Pairing requires matching a security code on both devices, and new devices start read-only.
Are projects or sessions uploaded to a Connect cloud?
No. Connect has no product account or cloud inference service. Projects stay on your Mac, app state stays in local userData, and mobile connects directly over a private network.
When will Mac and iPhone downloads open?
Mac needs Developer ID signing, Apple notarization, and the production update channel. iPhone needs App Store distribution signing and review. These pages remain honest until those artifacts exist.
Are Windows and Android supported?
Not yet. The site reserves their place without promising a download or release date. The current public targets are Apple silicon Mac and iPhone.
Public release

The download paths are ready. Production signing is still being closed.

Mac will ship as a Developer ID-signed, Apple-notarized DMG from this site. iPhone will ship through the App Store. Local and Personal Team builds will not be published.
