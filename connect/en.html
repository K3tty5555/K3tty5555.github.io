What you may want to know before installing.

Is Connect a terminal?
It is not another AI chat box. Claude, Codex, and shell panels all run real terminals. Connect manages the project, panels, collaboration, and iPhone connection.
Which coding agents are supported?
You can open Claude Code, Codex, and shell from the top bar. Other CLIs can run inside shell. Automated collaboration currently supports Claude and Codex.
Do I give Connect an API key or account?
No. You install and sign in to vendor CLIs yourself. Connect does not read vendor auth files, store or forward tokens, or provide a Connect AI account.
How do Claude and Codex collaborate?
Mention Claude or Codex in a room and Connect sends it the current room history. One agent runs one task at a time. Different agents and rooms can run together.
How does iPhone connect to Mac?
Mobile control is off by default on Mac. It only listens on Tailscale or a trusted LAN address. Pairing requires matching both security codes, and new devices start read-only.
Are projects or sessions uploaded to a Connect cloud?
No. Projects stay on your Mac and app data stays on the computer. iPhone connects directly over your private network.
When will Mac and iPhone downloads open?
Mac still needs Developer ID signing, Apple notarization, and the update channel. iPhone still needs App Store review. The download links stay closed until those steps are done.
Are Windows and Android supported?
Not yet. The current targets are Apple silicon Mac and iPhone. Windows and Android have reserved spots, but no release date.

The Mac DMG will appear here after Developer ID signing and Apple notarization. The iPhone app will ship through the App Store. Local test builds will not be published.
