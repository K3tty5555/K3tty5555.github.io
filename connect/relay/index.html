用自己的服务器连接手机

最后更新：2026 年 10 月 28 日

手机要连上你电脑里的 Connect，需要一条能互相找到对方的网络通道。Connect 默认推荐 Tailscale， 装好即可用，不需要服务器。本页是给另一种人准备的：你手上已经有一台云服务器，想自己架这条通道。

自己架的好处是这条通道完全归你，经过它的数据也只在你自己的机器之间流转。代价是要花十几分钟做一次 配置，之后基本不用管。

这个"中继"到底在做什么

手机和电脑都主动去连你的服务器，由它负责把两边接上，就像两个人各自打电话到同一个总机。

重要的是：服务器只负责转发，看不懂内容。 你的终端画面、文件、对话在离开电脑前就已经加密， 服务器拿到的是一团密文，解不开。它也不保存任何内容、不需要账号、不碰你的 Claude 或 Codex 登录状态。

这还意味着你不需要把电脑上的任何端口暴露到公网。

你需要准备什么

  • 一台能从公网访问的服务器（最便宜的云主机就够，中继本身几乎不吃资源）
  • 一个指向这台服务器的域名（例如 relay.yourdomain.com）
  • 服务器上装好 Docker

如果以上三样你都有，往下走大概十几分钟。如果没有服务器，用 Tailscale 就好，不必勉强。

第一步：把中继跑起来

连上你的服务器（在自己电脑的终端里执行，把地址换成你的）：

ssh 你的用户名@你的服务器地址

把中继的部署文件取下来，进入目录并启动：

git clone https://github.com/K3tty5555/connect-relay.git
cd connect-relay
cp .env.example .env
docker compose up -d --build

-d 的意思是在后台一直运行，关掉 ssh 窗口它也不会停。

第二步：生成一把钥匙

这把钥匙决定了谁能用你的中继——没有它，别人就算知道你的地址也连不上。

docker compose exec relay node /app/relay-server.mjs keygen

屏幕上会打印出一串以 ck_live_ 开头的字符。这串字符只会显示这一次，请立刻复制保存到你的密码管理器。 服务器上只留一份摘要，丢了没法找回，只能重新生成一把。

不要把它发到聊天工具、写进网址、贴进公开仓库。

第三步：配一个 https 地址

浏览器和手机都要求加密连接，所以中继需要一个 wss:// 开头的地址（可以理解成"给通道用的 https"）。

部署目录里的 Caddyfile.example 是一份现成的参考配置，照着改成你的域名即可。它会自动申请证书。 要点有两个：只放行 /v1/relay 这一个路径，不要把容器的 8787 端口直接开到公网。

弄好之后，你的地址形如：

wss://relay.yourdomain.com/v1/relay

第四步：填进 Connect

先在电脑上填：

设置 → 手机远程 → 展开高级设置，找到"外网 Relay"：

  1. 地址填 wss://relay.yourdomain.com/v1/relay
  2. API Key 填第二步保存的那串 ck_live_…
  3. 点"保存 Relay"

下面两栏"备用 Relay"可以留空。如果你有第二台服务器，填进去，主通道不通时会自动改走备用。

再在手机上填同样的内容：

手机 Connect 的设置里有相同的两栏，填完全一样的地址和 Key。两边不一致就会连不上。

填好后用手机扫码配对一次即可。配对本身也能走你自己的中继，不需要 Tailscale。

遇到问题

手机一直连不上

先确认地址以 wss:// 开头、结尾是 /v1/relay，两端一字不差。再在服务器上看日志：

docker compose logs -f relay

想换掉或停用这把钥匙

替换服务器上的 key 文件后重启容器即可立即生效：

docker compose restart relay

想完全不用中继了

在电脑设置里点"清除 Relay"，手机端同样清除，两边都会回到 Tailscale 或局域网连接。

几点说明

  • 中继不提供账号系统、管理后台，也不会列出你的项目目录——它只是一条通道。
  • 中继只转发加密帧，无法读取、也无法保存你的任何内容。
  • 如果多人共用一台中继，请给每个人单独生成一把钥匙，这样可以单独停用其中任何一把。
  • 服务器的带宽决定手机端看终端画面的流畅度。日常使用占用很小，但若你用手机长时间看网页镜像， 留意一下流量。
