Connect 隐私政策

版本：发布候选 1.0

最后更新：2026 年 8 月 25 日

生效日期：2026-08-25

本隐私政策说明 ketty Wu（以下称“Connect 运营方”或“我们”）在你使用 Connect Mac 应用、Connect iPhone 伴侣应用及与本政策链接的 Connect 官方网站时，如何处理与保护信息。 隐私联系邮箱为 w494892858@gmail.com。

Connect 是本地优先的工具。它没有 Connect 账号或云端模型服务。应用的主要数据保存在你控制的 Mac 和 iPhone 上；iPhone 只在你明确配对后，通过私有网络直接连接你自己的 Mac。

1. 适用范围

本政策适用于：

  • Connect Mac 应用及 Connect iPhone 伴侣应用；
  • 与本政策链接的 Connect 官方下载、支持和兼容性网页；
  • 你主动发送给我们的支持或隐私请求。

本政策不适用于 Claude、Codex、Tailscale、Apple 或其他独立第三方服务。你与这些服务之间的 关系受其各自条款和隐私政策约束。

2. 重要结论

  • 我们不通过 Connect 服务器收集你的项目文件、终端内容、提示词、模型回复、配对资料或凭据。
  • Connect 不含广告、行为跟踪、分析 SDK 或自动崩溃/诊断上传。
  • 我们不出售个人信息，不共享个人信息用于跨情境行为广告，也不创建广告画像。
  • Connect 不读取 Claude/Codex 的认证文件，不保存、代理或上传其 token、密码或 API key。
  • 只有当你明确运行第三方 CLI 或发送图片时，相应内容才可能由该 CLI 发送给其提供商。

3. 应用在你的设备上处理的信息

以下信息由 Connect 为提供你请求的功能而在你的设备上处理。除第 5 节所述的用户主动第三方操作 外，Connect 运营方无法访问这些信息。

4. Mac 与 iPhone 直连

移动桥默认关闭。只有你在 Mac 设置中明确开启后，它才会监听一个具体的 Tailscale 或局域网私有 地址；Connect 不使用公网中继、Tailscale Funnel、UPnP 或 NAT 端口映射。

配对要求你扫描二维码并在两台设备上核对短认证字符串。连接使用应用层加密与设备身份校验。 新设备默认只能读取；写入权限必须在 Mac 上独立授予，并可随时收回或吊销。安全审计不记录 终端内容、提示词、模型回复、文件内容或 token。

5. 第三方 CLI 和服务

Claude 与 Codex

Claude Code 和 Codex CLI 由你自行安装、订阅并登录。Connect 只启动和编排本机 CLI，不提供 第三方账号、模型、token、订阅或额度。

当你明确向 Claude 或 Codex 发送命令、图片或协作任务时，该 CLI 可能把以下内容发送给对应 提供商：你的输入、你选择的图片、为完成任务读取的工作区内容，以及 CLI 自己生成的技术元数据。 具体发送内容、保留期限、训练选择和地区处理由你的第三方账号设置及对应提供商政策决定。请查阅：

  • Anthropic 隐私政策：https://www.anthropic.com/legal/privacy
  • OpenAI 隐私政策：https://openai.com/policies/privacy-policy/

Connect 不会代表你接受这些提供商的条款，也不会绕过其 CLI 的登录或首次确认流程。 这些服务由你独立选择，Connect 运营方不委托它们代表我们收集应用数据。如果未来由我们委托服务商 处理应用数据，我们会在启用前更新本政策，并要求其提供不低于本政策和适用法律要求的保护。

Tailscale

如果你选择使用 Tailscale，Connect 只使用 Tailscale 分配给你设备的私有地址建立设备直连。 Connect 不包含 Tailscale SDK，不管理你的 Tailscale 账号。Tailscale 可能依据其自身政策处理设备 和连接元数据：https://tailscale.com/privacy-policy。

Apple

Apple 可能为 App Store 分发、系统权限、系统诊断和商店交易独立处理信息。该处理受 Apple 的 政策和你的 Apple 设置约束；Connect 运营方不会通过应用接收 Apple 的系统诊断，除非你主动选择 向我们发送相关内容。

6. 设备权限

  • 相机：仅用于扫描 Mac 上的配对二维码。Connect 不录制、保存或上传照片和视频。
  • 照片选择器：只有你明确选择的图片会进入终端或协作发送流程。Connect 不请求浏览整个相册。
  • 局域网：用于发现或连接你自己的 Mac。拒绝权限后，你可以在系统设置中重新授权。

你可以随时在 iOS“设置”中撤回系统权限。撤回后，依赖该权限的功能会停止，但其他功能继续可用。

7. 官方网站和支持通信

Connect 官方网页不使用广告、跟踪像素或分析脚本。为交付网页和防止滥用，网站托管/CDN 服务商 可能临时处理 IP 地址、请求时间、请求路径、浏览器或 User-Agent、响应状态和安全事件。正式部署 必须选择承担适当保密和安全义务的服务商，并把普通访问日志保留期配置为不超过 30 天；因安全 事件或法律义务需要更久保留的除外。

当你主动通过邮件或其他支持渠道联系我们时，我们会处理你的联系信息、消息及你选择附带的文件， 仅用于响应请求、解决问题和保存必要的合规记录。普通支持记录在工单关闭后最多保留 24 个月； 法律要求、争议处理或你要求提前删除的情形除外。请不要发送密码、token、私钥或不必要的项目内容。

9. 安全

Connect 使用 Workspace Trust、规范路径和符号链接边界、沙箱化渲染进程、系统安全存储、设备配对、 认证加密、最小权限、授权吊销、限频和有界无内容审计等措施降低风险。公开 Mac 版本还要求 Developer ID 签名和 Apple 公证。没有任何软件或传输方式能够保证绝对安全；请只信任你了解来源 的工作区，并保护你的设备、第三方账号和私网环境。

10. 跨境处理

Connect 运营方不会把应用本地数据传输到自己的服务器。你主动使用的第三方 CLI、Tailscale、 Apple、网站托管/CDN 或支持服务可能在其运营国家或地区处理信息，并依据其政策使用适用的传输 机制。是否使用这些独立服务由你决定。

11. 你的权利和选择

根据适用法律，你可能有权访问、更正、删除、限制或反对我们持有的个人信息，撤回同意，获取副本， 以及向监管机构投诉。由于应用主要数据只在你的设备上，我们通常没有可用于响应请求的服务器副本； 你可以直接在设备上查看、修改或删除这些数据。对于网站日志或你主动发送的支持记录，请通过 w494892858@gmail.com 提交请求。我们可能需要验证请求身份，且法定例外可能适用。

我们不出售或共享个人信息用于跨情境行为广告，不使用敏感个人信息推断特征，也不因你行使隐私 权利而歧视你。

12. 未成年人

Connect 是开发工具，不面向 16 岁以下儿童，也不申请进入 App Store 儿童类别。我们不会明知故意 通过 Connect 服务收集儿童个人信息。如果你认为儿童向我们提交了支持信息，请联系我们处理。

13. 政策变更

我们会在产品能力、第三方接收方或法律要求变化时更新本政策，并修改“最后更新”日期。重大变化会 通过应用内提示、官方网站或其他适当方式通知。若未来增加 Connect 账号、云同步、遥测、崩溃上传、 广告或新的远程服务，我们会在启用前更新政策和必要的用户选择。
