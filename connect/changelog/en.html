Release notes

Mac

Download for Mac

  1. 1.0.17

    2026-10-25Latest
    • New "Start Right Away" on the home screen: no folder to pick first. One click opens a scratch workspace with Claude.
    • The toolbar's new-panel buttons can be hidden and reordered in Settings → Toolbar Buttons, and you can add your own command buttons (such as Kimi or Qwen) with an icon.
    • Kimi Code is built in: turn it on in Toolbar Buttons. Its status lamp shows running, waiting for you, and done.

  2. 1.0.16

    2026-10-25
    • Panel tabs now show what Claude / Codex is working on; double-click a tab or choose "Rename" to name it yourself. The phone's session list shows the same name.
    • Fixed Claude occasionally writing at a very narrow width after switching workspaces.

  3. 1.0.15

    2026-10-24
    • When the phone drops off (backgrounded or a network blip), it keeps control of the terminal; it picks up where it left off on return, and you can take it back on the Mac with "Continue on computer" or by typing.
    • Fixed mobile viewing occasionally falling back to compatibility terminal mode, with Restore spinning forever.
    • "Mobile app" in Settings now opens the download page, with both iPhone and Android.

  4. 1.0.14

    2026-10-23
    • Mobile access now follows your Mac across network changes without re-pairing; Relay connections stay up throughout.
    • Command and environment probes in Settings are noticeably faster (cached login shell environment).

  5. 1.0.13

    2026-10-21
    • Fixed the Mobile Access settings failing to open with "invalid MobileBridgeStatus" once a Relay was configured.

  6. 1.0.12

    2026-10-21
    • Relay settings now show the saved address, so you no longer re-enter it after reopening Connect; leave the API key blank to keep the saved one.
    • Fixed the backup Relay not saving and an empty form wiping the Relay settings on save; clearing is now a separate button.
    • Connect reconnects to the Relay right away after a drop; with the new mobile app, remote control comes back faster after the phone returns from the background or the Mac restarts.
    • Clearer spacing between the Relay setting fields.

  7. 1.0.11

    2026-10-20
    • Fixed pairing over a private relay stalling on the phone after confirming the security code on the Mac.
    • Fixed relay connections being forced to reconnect every 90 seconds; remote sessions now stay connected.

  8. 1.0.10

    2026-10-19
    • Fixed an intermittent issue where Claude Code history could not be scrolled upward on Windows.
    • Private Relay pairing now opens with a Relay QR code when Relay is configured.
    • Added clearer Relay pairing errors for invalid keys, expired tickets, and capacity limits.

  9. 1.0.9

    2026-10-18
    • Fixed private Relay first pairing so Mac and phone do not need Tailscale or the same local network first.
    • Fixed Relay startup when no usable LAN address is available; Relay-only mode does not open a local Mac listener.
    • Added clear save feedback after Relay settings are stored on Mac and mobile.
    • Relay connection failures no longer incorrectly tell users to check Tailscale.

  10. 1.0.8

    2026-10-18
    • Fixed an issue where the window opened but showed no content after updating to 1.0.7.
    • Fixed a sandbox preload failure that caused a blank desktop first frame.
    • Kept Relay pairing QR validation aligned with the main-process contract validation.

  11. 1.0.7

    2026-10-18
    • Added private Relay remote control: phones can pair through the user's own Relay without first joining Tailscale.
    • Relay pairing uses a one-time ticket and a device credential; the user API Key is never put in the QR code.
    • Relay settings now live under Advanced Settings and support a backup Relay endpoint with automatic failover before authentication.
    • Relay servers now enforce health checks, connection and ticket limits, expiry cleanup, and graceful shutdown.
    • Fixed: a revoked device's old Relay credential can no longer reconnect.

  12. 1.0.6

    2026-10-14
    • Preview Word and Excel files right in the panel, no need to switch apps.
    • HTML files get an "Open in Browser" button to see the page as it renders.
    • The file tree and file tabs now use colored file-type icons, so Word, Excel, video and more stand out at a glance.
    • File preview buttons now sit on the path row and collapse to icons in narrow panels instead of wrapping.
    • The Codex status lamp now tells the truth: yellow while running, red when it needs your approval.
    • Linked devices can be renamed in Settings.
    • Fixed: clicking a link in a Codex reply showed an English confirmation box; it now offers "Copy Link / Open in Browser", and local addresses with a port open too.
    • Fixed: a small hollow box appearing in conversation text on the phone.

  13. 1.0.5

    2026-10-13
    • Long lines in the file viewer now wrap to the panel width instead of scrolling sideways.
    • Status lamps in the sidebar and panel tabs now use the same red, yellow and green as the window buttons.
    • Fixed: one-click install of Claude Code / Codex reported failure even when it had succeeded.

  14. 1.0.4

    2026-10-11
    • The menu bar follows the interface language (Simplified Chinese, Traditional Chinese, English).
    • The sidebar and panel tabs use a single status light: red means a new result or something waiting for you, yellow means running, green means all done.
    • Closing a group chat also stops the /auto task it is running.
    • Link popovers in the terminal appear next to the link, and Chinese punctuation right after a link is no longer treated as part of it.
    • Starting with this version, in-app updates retry from an alternate download address when GitHub is unreachable or the download is interrupted.

  15. 1.0.3

    2026-10-09
    • If an in-app update download is interrupted, you can retry it or download the installer from the website instead.

  16. 1.0.2

    2026-10-07
    • When an update is available, a notice appears in the project title bar. Click to download, then choose Restart to Update. The Settings button shows a dot too.
    • Before restarting to install, Connect tells you if terminals, chats, or collaborations are still running.

  17. 1.0.1

    2026-10-07
    • iPhone and iPad can browse this Mac's project files, and create, rename, move, and edit them.
    • Fixed: after a project folder was renamed outside Connect, the project could not be closed on Mac and iPhone could not connect.
    • When closing a project fails, Connect now says why and what to do next.

  18. 1.0.0

    2026-10-04
    • First public release, Developer ID signed and notarized by Apple.

iPhone / iPad

Download on the App Store

  1. 1.0.10

    2026-10-22Latest
    • After the app has been in the background, or the next day, Connect reconnects quickly on its own when you return; no manual reconnect needed.
    • With a private relay, the phone now waits and connects automatically when the computer is briefly offline (asleep or restarting).
    • Changing Relay settings on the phone no longer loses the pairing.

  2. 1.0.9

    2026-10-21
    • Pair and connect through a relay you host yourself; Tailscale or the same Wi-Fi network is no longer required.
    • The terminal now uses a native renderer: complete output, opens at the latest line, with no duplicated or missing lines and no font-size jumps.
    • Projects and sessions show the same status lights as on the Mac, and results you read on the phone are cleared on the Mac too.
    • Preview Word and Excel files; file lists and iPad tabs now use colored file-type icons.
    • Fixed an extra blank row under the iPad tab bar and several pairing and connection issues.

  3. 1.0.3

    2026-10-10
    • New Files tab: browse the whole project, create, rename, delete (to the Mac's Trash), copy, cut and paste, edit text, and preview images and PDFs.
    • Scrolling back through terminal history now shows a Jump to Latest button in the corner.
    • iPadNew layout with projects and files in a sidebar, and sessions, files, and settings in tabs, with Split View support.

  4. 1.0.0

    2026-10-09
    • First public release: connect back to your own Mac to view and take over Claude, Codex, and terminal sessions.
