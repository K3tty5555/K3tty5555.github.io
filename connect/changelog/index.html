Mac

下载 Mac 版

  1. 1.0.5

    2026-10-13最新
    • 打开文件时，超长行自动按窗口宽度换行，不用再横向滚动。
    • 侧栏与面板标签的状态灯，改用与系统窗口按钮一致的红黄绿，更醒目。
    • 修复：设置里一键安装 Claude Code / Codex，明明装成功了却提示安装失败。

  2. 1.0.4

    2026-10-11
    • 顶部菜单栏跟随界面语言（简体中文、繁體中文、English）。
    • 侧栏和面板标签改为一盏状态灯：红色是有未读结果或在等你处理，黄色是正在运行，绿色是都已完成。
    • 关闭群聊时，会一并停止它正在进行的 /auto 任务。
    • 点击终端里的链接，弹窗出现在链接旁边；链接后紧跟中文标点时，不再被算进链接。
    • 从这一版起，应用内更新在 GitHub 连不上或下载中断时，会自动改用备用下载地址重试。

  3. 1.0.3

    2026-10-09
    • 应用内更新下载中断后，可以直接重试，或改从官网下载安装包。

  4. 1.0.2

    2026-10-07
    • 有新版本时，项目标题栏会出现一行提示，点一下下载，下载完点「重启以完成更新」；设置按钮上也会有小圆点。
    • 重启安装更新前，如果还有终端、对话或协作在运行，会先告诉你。

  5. 1.0.1

    2026-10-07
    • 手机和 iPad 可以浏览这台 Mac 上的项目文件，并新建、重命名、移动和编辑文件。
    • 修复：项目文件夹在 Connect 之外被改名后，Mac 上关不掉这个项目、手机也连不上。
    • 关闭项目失败时，会说明原因和下一步该怎么做。

  6. 1.0.0

    2026-10-04
    • 首个公开版本：经 Developer ID 签名和 Apple 公证，从官网下载安装。
