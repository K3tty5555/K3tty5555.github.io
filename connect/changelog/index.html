Mac

下载 Mac 版

  1. 1.0.20

    2026-10-29最新
    • 修复：中文输入法下打出的标点变成英文标点（「，」变成「,」）。终端、Claude、Codex 各面板都已修正；英文输入法、命令里的符号与 Ctrl+C 中断不受影响。
    • 手机看网页：画面改为撑满手机屏幕。此前电脑上的网页面板是窄长条时画面会被裁掉，是宽面板时屏幕上只有一小条、下面一大片空白。
    • 手机看网页：画面刷新明显变流畅，尤其在手机用流量、经中继连接时。

  2. 1.0.19

    2026-10-28
    • 新增「网页」面板：在 Connect 里直接打开本机服务地址（localhost 等）和项目里的 HTML 文件；终端里的本机链接可一键「在 Connect 中打开」，文件树右键可「在 Connect 中预览」。
    • 顶部工具栏新增「网页」按钮，可在设置的顶部按钮列表里自定义显示与顺序。
    • 手机、平板远程可以查看并操作电脑上的网页面板（需手机版同步更新到 1.0.15）。
    • 修复：保存 Relay 设置或关闭再开启手机远程后，手机的下一次接管可能被电脑忽略的问题。

  3. 1.0.18

    2026-10-26
    • 修复：文件树里的 Git 状态标记（已修改、新文件等）从 1.0.14 起不再显示，现已恢复。
    • 外网 Relay 改了地址时需要重新填写 API Key，旧 Key 不会再发给新地址。
    • 顶部按钮设置更稳：连续快速调整不再丢改动；按钮名字里用 emoji 也不会让自定义按钮消失。
    • Kimi Code 的状态灯不再在思考与调用工具之间闪成完成；按 Esc 中断后不再提示「响应完成」。
    • 以后如果装回旧版本，设置不会再被清掉。

  4. 1.0.17

    2026-10-25
    • 首页新增「直接开始」：不用先选文件夹，点一下就进入草稿工作区并打开 Claude。
    • 顶部新建按钮可在「设置 → 顶部按钮」里隐藏、调整顺序，也可以添加自己的命令按钮（如 Kimi、通义等），并选图标。
    • 预置 Kimi Code：在「顶部按钮」里打开即可使用，状态灯会显示运行中、等你处理与完成。

  5. 1.0.16

    2026-10-25
    • 面板标签显示 Claude / Codex 当前在做的事；双击标签或右键「重命名」可以自己起名，手机会话列表同步显示。
    • 修复切换工作区后 Claude 偶尔按很窄的宽度输出的问题。

  6. 1.0.15

    2026-10-24
    • 手机切后台或网络抖动断开后，接管不再自动还给电脑；手机回来接着用，电脑上点「在电脑上继续」或直接打字即可收回。
    • 修复手机远程查看时偶尔掉进「兼容终端模式」、点恢复一直转圈的问题。
    • 设置里的「手机 App」改为打开官网下载页，iPhone 与 Android 都在上面。

  7. 1.0.14

    2026-10-23
    • 电脑换网络后手机远程自动跟随，不再需要重扫二维码；Relay 连接全程不受影响。
    • 设置页的命令与环境探测明显变快（登录 shell 环境缓存）。

  8. 1.0.13

    2026-10-21
    • 修复配置过外网 Relay 后，设置里的「手机远程」整块无法打开、提示 invalid MobileBridgeStatus 的问题。

  9. 1.0.12

    2026-10-21

    • 修复备用 Relay 保存不上、空表单点保存会清掉 Relay 设置的问题；清除改为单独的按钮。
    • 与 Relay 的连接断开后会立即重新连上；配合新版手机端，手机切后台回来、Mac 重启后都能更快恢复远控。
    • 外网 Relay 设置的输入框间距调整得更清楚。

  10. 1.0.11

    2026-10-20

    • 修复 Relay 连接每 90 秒被强制断开的问题,远控连接现在保持稳定。

  11. 1.0.10

    2026-10-19

  12. 1.0.9

    2026-10-18
    • 修复私人 Relay 首次配对：Mac 和手机都不需要先连接 Tailscale 或处在同一局域网。
    • 修复没有可用局域网地址时 Relay 无法启动的问题，Relay-only 模式不会打开 Mac 本地监听端口。
    • Mac 和手机保存 Relay 后显示明确的保存成功反馈。
    • Relay 连接失败时不再误提示检查 Tailscale。

  13. 1.0.8

    2026-10-18
    • 修复：1.0.7 更新后窗口打开但内容为空的问题。
    • 修复：sandbox preload 加载失败导致的桌面首屏白屏。
    • 保持 Relay 配对二维码校验与主进程契约校验一致。

  14. 1.0.7

    2026-10-18
    • 新增私人 Relay 远控：手机首次配对也可通过用户自己的 Relay，不再必须先连接 Tailscale。
    • Relay 连接使用一次性配对 ticket 和设备级 credential；用户 API Key 不进入二维码。
    • 远控设置把 Relay 配置收进「进阶设置」，支持备用 Relay 地址，主 Relay 不可用时自动切换。
    • Relay 服务端增加健康检查、连接/票据上限、过期清理和安全退出。
    • 修复：Relay 设备被吊销后，旧 credential 无法继续连接。

    • 文件树与文件标签换成彩色类型图标，Word、Excel、视频等一眼可辨。
