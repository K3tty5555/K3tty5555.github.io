常见问题

在安装前，把边界说清楚。

Connect 是一个终端吗？
Connect 是 GUI-first 的多 agent 工作空间。每个 Claude、Codex 或 Shell 面板底层仍是真实终端；Connect 负责组织项目、面板、协作与移动控制。
支持哪些 coding agent？
顶部提供 Claude Code、Codex 和 Shell 的固定入口。任何能在终端运行的 CLI 都可以从 Shell 使用；当前自动协作引擎只对 Claude 与 Codex 提供明确支持。
需要把 API Key 或账号交给 Connect 吗？
不需要。你自行安装并登录厂商 CLI。Connect 不读取厂商 auth 文件，不保存或转发 token，也不提供 Connect AI 账号。
Claude 和 Codex 如何协作？
协作群把完整房间记录交给被 @ 的 agent。你可以让 Claude 实现、Codex 复审；同一 agent 保持串行，不同 agent 与不同房间可以并行。
iPhone 如何连接 Mac？
Mac 上的移动桥默认关闭，只绑定具体 Tailscale 或 RFC1918 私网接口。配对需要双端核对安全码，新设备默认只有读取权限。
项目和会话会上传到 Connect 云端吗？
不会。Connect 没有产品账号或云端推理服务。项目留在你的 Mac，应用状态存放在本地 userData；移动端通过私网直连自己的 Mac。
Mac 和 iPhone 什么时候可以公开下载？
Mac 版需要完成 Developer ID 签名、Apple 公证和下载更新管线；iPhone 版需要 App Store 生产签名与审核。当前页面会保持诚实的“准备发布”状态。
Windows 和 Android 已经支持了吗？
尚未。网站只预留规划位置，不提供下载承诺或发布日期。当前公开目标是 Apple silicon Mac 与 iPhone。
