Claude ↔ Codex

把“实现—复审—收敛”变成一条可见的协作链。

你决定目标，Connect 负责把上下文和结果放回同一个房间。每个 agent 仍使用你本机已经安装、已经登录的官方 CLI。

  1. 01你提出任务

  3. 03Codex 复审
  4. 04结果回到协作群

Mac + iPhone

离开电脑，也能继续掌握现场。

通过 Tailscale 私网或受信任的局域网连接自己的 Mac。手机可以查看已有会话、接管输入、归还控制权，并在协作群里继续跟进。
